# taskflow-internship
A responsive SaaS landing page for TaskFlow, a project management platform concept. Built using HTML5, CSS3 and JavaScript, featuring a modern dark-purple design, feature cards, pricing plans, responsive navigation and an interactive demo request form. Created as part of the Sankar Group Front-End Development Internship Assignment.



# TaskFlow – SaaS Landing Page

TaskFlow is a responsive SaaS landing page concept
for a project and task management platform.

## Features
- Responsive navigation
- Hero section and dashboard preview
- Feature cards
- How it works section
- Pricing plans
- Contact form with validation
- Mobile-friendly layout

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Alternatively, use the Live Server extension.

## Project Type
Front-End Development Internship Assignment

Note: This is a front-end demonstration.
The contact form does not connect to a backend.
